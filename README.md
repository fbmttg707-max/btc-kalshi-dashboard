# BTC/Kalshi Phone-First Dashboard

Phone-first FastAPI dashboard for live BTC analytics and short-horizon paper signals.

Run:
1. `pip install -r requirements.txt`
2. `python server/main.py`
3. Open `http://localhost:8000` on the device/browser.

This is analytics/paper mode. It does not place trades and does not guarantee accuracy. Before using it to evaluate Kalshi contracts, add a verified official settlement/reference feed and backtest against actual contract outcomes.
